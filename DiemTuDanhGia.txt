KY THUAT
- Cau truc du lieu: HashMap<String,ArrayList<Long>>, HashMap<Long,SlangEntry>, ArrayList + binary search (goi y prefix).
- Luu cau truc da index (dictionary.dat: magic + version ID + CRC32), lan sau khong index lai; backup .bak; slang.working.txt cung version ID.
- File goc slang.raw.txt giu nguyen; slang.normalized.txt chuan hoa mot lan; malformed-report.txt liet ke tung dong (khong bo qua dong nao).
- Unit test: 140 test JUnit 5;
- Benchmark 7 vong: docs/benchmarks/benchmark-100k.txt (Add/Edit/Delete/Reset co luu, trung vi 0.2-0.45 s).

- File JAR chay duoc: dist/SlangDictionary.jar (java -jar dist/SlangDictionary.jar), thu muc dist/data di kem.
